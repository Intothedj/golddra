# 황룡 각인 시뮬레이터

게임 각인 창을 참고한 금색 테두리·짙은 남색 배경의 반응형 웹페이지입니다. 비서 각인/시도 기록 탭과 진행 효과를 제공합니다.

HTML, CSS, JavaScript만으로 동작합니다. 설치나 빌드, API 키가 필요 없습니다.

## 파일

- `index.html`: 화면 구성
- `styles.css`: PC/모바일 반응형 디자인
- `app.js`: 확률 추첨, 비서별 실행, 기록, 비용 계산
- `assets/red.png`, `assets/white.png`: 제공받은 비서 이미지
- `.nojekyll`: 정적 파일 제공용 빈 파일

## 실행

압축을 모두 푼 뒤 `index.html`을 브라우저에서 엽니다. 파일과 assets 폴더의 위치 관계를 유지하세요.

Python이 설치되어 있다면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`에서도 확인할 수 있습니다.

## GitHub 업로드

ZIP을 압축 해제한 **내용물**을 저장소 최상위에 올리세요. ZIP 자체만 업로드하면 웹페이지로 실행되지 않습니다. `index.html`과 `assets` 폴더가 저장소 최상위에 있어야 합니다.

GitHub Pages로 제공하려면 업로드한 브랜치의 루트 디렉터리를 배포 대상으로 사용하세요. 일반 정적 호스팅에서도 동일한 파일로 동작합니다.

## 동작

- 빨간색: [황룡]잠재력각인비서, 독립 성공 확률 3%, 기본 가격 90,000,000 머니
- 하얀색: [황룡]희귀잠재력각인비서, 독립 성공 확률 5%, 기본 가격 180,000,000 머니
- 각 카드의 버튼은 해당 비서만 설정한 횟수(1~10,000회)만큼 실행합니다. 성공 후에도 설정 횟수까지 진행합니다.
- 성공할 때까지 시도: 선택한 비서로 첫 성공까지 반복합니다.
- 중지: 결과를 보존하며 실행을 중단합니다.
- 기록 초기화: 실행을 중단하고 기록과 비용 통계를 지웁니다. 입력 가격, 횟수, 비서 선택 및 기록 필터는 유지합니다.
- 가격 변경은 이후 시도부터 적용됩니다. 이전 기록은 당시 가격을 유지합니다.
- 최근 성공까지 비용: 직전 성공 다음 시도부터 이번 성공까지의 비서 비용을 합산합니다. 최초 성공은 첫 시도부터 합산합니다.
- 페이지를 새로고침하거나 닫으면 기록과 설정은 유지되지 않습니다. 서버 저장 및 사용자 정보 수집은 없습니다.

확률은 사용자 제공값이며 실제 게임 결과를 보장하지 않습니다. 이미지 자산은 제공받은 원본을 포함하며 별도의 이용허락이나 라이선스를 부여하지 않습니다.
